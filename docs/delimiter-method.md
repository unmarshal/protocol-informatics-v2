# Delimiter-terminated record method

Use `probe-delimiter <dir> <observation-id> <start-offset> <delimiter-hex>` to test a specified terminator in one binary or TCP-stream observation. The delimiter is 1–4 bytes, expressed as even-length hex. The start offset is a byte index in the observation. Each returned record uses half-open offsets: `[start, payload_end)` contains the payload and `[payload_end, end)` contains the terminator. The probe reports up to 256 records, a status and next offset when parsing stops, a short byte preview, and original file offsets or clipped TCP source spans. At most 16 spans appear per record; use paged `span` for the full provenance.

`infer-delimiter <dir> <discovery-trial> <validation-trial>` searches one experiment's distinct trials. It needs at least two different discovery observations. It takes 1–4-byte suffixes of the first discovery observation as candidate terminators and tries start offsets 0–8. A candidate must parse every discovery observation into at least three complete, nonempty records, with varying payload lengths across the trial. It then checks every held-out validation observation and reports matches and bounded counterexamples. It inspects at most 16 observations per trial and 64 KiB per observation.

The fixture generator `python3 examples/generate_delimiter_fixture.py` writes four independent test observations and a fifth with an unterminated tail. The two discovery files end records with CRLF. One validation file uses CRLF; another uses LF. Both `0d0a` and `0a` can fit the discovery files, but `0d0a` fails on the LF-only validation file. A `0a` fit still treats each preceding CR byte as payload in the CRLF files. The output is a set of structural candidates, not a semantic ruling about where payload ends.

An `unterminated_record` status leaves the final bytes unassigned; `empty_record` stops at a zero-length payload; `record_limit` means more data remains after the cap. The method does not model escapes, quoting, length fields, blank records, or nested delimiters. A delimiter inside payload bytes can create plausible but wrong boundaries. Use controlled experiments and further held-out captures before promoting a candidate to a protocol description. Delimiter probes are read-only; there is no committed delimiter-frame model yet.
